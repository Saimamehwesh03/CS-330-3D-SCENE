## 1. How do I approach designing software?

When designing software, I try to understand the requirements first and break the project into smaller parts. ## 2. How do I approach developing programs?

While working on my 3D scene, I learned the importance of writing code in smaller sections and testing it regularly. I used iteration to improve the scene by adjusting objects, positions, sizes, materials, and lighting until the result was closer to what I wanted. When something did not work as expected, I reviewed the code and made corrections instead of starting over. Throughout the milestones, I became more comfortable building on earlier work and improving it gradually. I can use these strategies in future programming projects to make development more organized and easier to troubleshoot.
